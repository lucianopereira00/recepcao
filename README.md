# Sistema de Recepção e Farmácia

Projeto desenvolvido em Java com o objetivo de praticar programação orientada a objetos, organização de classes e desenvolvimento de funcionalidades para gerenciamento de uma fila de recepção e de uma farmácia.

## Funcionalidades

### Recepção
- Gerenciamento de fila de pacientes.
- Classificação de pacientes por nível de urgência.
- Menu de atendimento.
- Menu administrativo.
- Consulta de informações e quantidades de pacientes por nível de urgência.

### Farmácia
- Módulo em desenvolvimento.
- Estrutura inicial para implementação do gerenciamento de medicamentos e estoque.

## Tecnologias utilizadas

- Java
- Maven
- Git e GitHub
- IntelliJ IDEA

## Objetivos do projeto

- Praticar os fundamentos da linguagem
